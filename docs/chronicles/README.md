# Project Chronicles

This directory records task-specific maintenance history for Chronicle Stack.

Use it for concise entries that explain what was inspected, what changed, what meaning was
preserved, what assumptions were introduced, and what should be re-evaluated later.

## Entry Template

```md
# YYYY-MM-DD - Short Task Name

## Chronicle Entry

- Date:
- Task:
- Baseline:
- Changed:
- Preserved:
- Why:
- Next:
- Re-evaluate when:

## Failure Note

- What happened:
- Why it happened:
- What changes next time:
- What to check again:
```

## Boundary

Chronicles are append-only maintenance history. Do not overwrite prior entries to make the
project history cleaner. If a prior entry is wrong, add a correction entry that explains the
change.
